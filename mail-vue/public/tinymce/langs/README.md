This is where language files should be placed.

Please DO NOT translate these directly, use this service instead: https://crowdin.com/project/tinymce

The editor language packs in this directory were taken from the TinyMCE 7
community language archive. Available languages are selected in
`src/ui/editor-locales.js`. When a community pack is unavailable, the editor
uses its built-in English controls while the surrounding mail interface keeps
the selected language.

Archive:
https://download.tiny.cloud/tinymce/community/languagepacks/7/langs.zip
