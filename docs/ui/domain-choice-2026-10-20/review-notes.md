# 域名选择界面复核

范围：临时邮箱地址卡片、后缀选择、历史列表及手机顺序。设计图先于产品实现保存；当前产品与设计模拟分别展示。

## 独立复核与修复

| 发现 | 修复 | 验证方式 |
| --- | --- | --- |
| 长用户名导致历史行隐藏后缀，同名多域名难以区分 | 地址完整换行 | 使用真实21字符随机用户名，检查历史地址没有水平裁切 |
| 域名切换未完成时提交失败查询，选择框可能与当前地址不一致 | 手动查询中止旧操作时恢复已接受的选择 | 挂起域名查询、提交不支持的域名、释放旧请求，检查地址和后缀 |
| 手机视觉顺序与键盘顺序不同 | DOM先地址、再收件箱；桌面通过网格定位 | 检查DOM先后及手机实际坐标 |
| 截图捕获切换动画中间帧 | 等待有限动画完成后保存 | 图像人工复核，不以过渡态判断持续产品状态 |
| 工作端印地语显示方框 | 补充实际Mac浏览器观察 | 生产页面375px印地语显示正常；工作端方框图不作为字体可读性通过证据 |

## 验收边界

自动化浏览器使用受控邮件数据，未发送真实邮件。新增控件与相邻文字的计算样式对比度最低5.32:1；这是限定控件的测量，不是全站主题认证。实际设备环境光阅读和所有语言的逐页人工审核未执行。生产域名配置及地址切换另行记录，不把模拟测试当作生产证明。

## 最终结论

限定范围放行。最终四张实现截图已独立只读复核：历史地址完整、正文无动画残影、阿语深色及印地语字形正常。测试及生产结论依据交付记录，独立审阅未另行运行测试。最终生产版本f6ec2fce-5531-40d5-9843-500aa72f2010。
