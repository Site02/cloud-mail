# 语言系统验收记录 · 2026-10-03

## 范围与结果

本地正式构建在隔离浏览器会话中完成验收。已提供的 16 种语言均从新会话直接打开公开邮箱；在 320px 宽度下，页面完成加载、一次性 `lang` 参数被移除、语言选择和常用控件的辅助名称有效，未见横向溢出或页面脚本异常。阿语为从右到左布局，繁体中文使用 `zh-TW`。

阿语和繁体中文从公开邮箱进入登录页，再返回公开邮箱，手动选择的语言、页面方向和两类安装清单保持一致。自动跟随浏览器时不强制覆盖另一入口已有的手动偏好。URL 中其他查询字段和片段标识在移除 `lang` 后保留。320、375、1440px 下语言与安装入口可用；语言对话框的搜索框能获得焦点，按 Escape 后焦点返回入口。

## 失败恢复

- 非英语首屏动态语言资源首次返回 503 时，页面显示已载入的英语、英语安装清单和重试入口；资源恢复后点击重试，新页面重新请求资源并切换到目标语言。
- 从英语页面手动选择日语时若资源首次返回 503，选择器保留实际英语状态并显示重试；资源恢复后重试会以日语重新载入。
- 直接打开阿语、繁体中文、德语和日语入口已验证可正常启动；此前的首屏循环等待已消除。

## 代码与资源检查

前端测试 24/24、服务端语言测试 5/5、服务端单元测试 26/26 通过。32 份安装清单与语言注册表一致，正式构建和部署预检通过。公开附件不存在的 404 响应禁止缓存。合并主线新增的 Webhook 界面文案已覆盖 16 种语言；查询接口只报告密钥是否已设置，密钥本身不返回。

## 证据边界

本地登录配置使用模拟响应；真实登录接口、登录后页面、实体手机安装、实际邮件正文与附件下载尚未在本轮正式构建中端到端验收。上述浏览器结论不代表全部 16 种语言的逐句母语审校，也不代表 85 种未发布语言已达到上线质量。

## 生产复核

合并主线后的版本 `444dfece-a000-40ff-aa5e-4473215f8d50` 已发布到公开邮箱和登录站点。公开页、登录页、公开配置及域名接口均返回 200；阿语与繁中安装清单返回正确的语言、方向和启动地址。阿语请求失效附件返回 404 和 `Cache-Control: no-store`。数据库新增字段已先于版本切换完成，随后初始化成功。

只读生产浏览器复检中，320px 阿语公开页与繁中登录页完成加载，页面方向、标题、移动端语言入口和双站安装清单匹配；跨域或站内跳转后手动语言保持。`ja-JP` 浏览器在桌面宽度自动匹配日语。语言弹窗搜索框获得焦点，按 Escape 后焦点返回按钮；页面无横向溢出或脚本异常。两站公开配置接口均返回正常数据。本次未登录、创建邮箱或安装到实体设备，因此实际邮件、附件和本地缓存没有在生产环境做端到端操作。

## 本轮增量复验

语言选择器继续只提供 16 种完整词典。应用词典现有 498 项、服务端词典 128 项；候选准入检查增加账户软删、永久删除、权限树加载失败和删除策略变化等高风险键，并加入故意保留英文的负例。公开邮箱本地历史提示已明确浏览器配置文件与独立安装应用各自的保存范围，不承诺安装后自动迁移，也不由本站自动清理。

独立浏览器验收在本地模拟接口中覆盖 16 种语言的 320px 和 375px 公开邮箱历史：长地址省略、邮件计数完整可见，德语、法语及阿拉伯语从右到左页面没有裁切或横向溢出。角色权限树首次请求失败时无法保存；编辑中失败会禁用保存，重试后原选中权限仍在。账户删除测试覆盖软删、永久删除、确认前重新读取方式，以及服务端发现方式变化时的 409 错误；没有执行真实账户删除。

前端测试 31/31、服务端单元测试 44/44、服务端语言测试 8/8、32 份安装清单检查和正式构建均通过。附件对象删除失败保留可重试的记录，站内投递为每个收件副本创建独立对象键并同步改写正文图片引用；这些路径经过本地集成回归。数据库与对象存储之间没有跨系统事务，多步写入失败仍可能产生临时孤立对象或需要重试的元数据。已删除或禁用账户的旧令牌会被数据库状态立即拒绝；账户快速恢复、登出和改密时的旧令牌撤销仍依赖分布式缓存传播，后续需要数据库中的会话撤销状态才能完全消除。

本轮浏览器验收使用模拟数据，未在实体手机上安装，也未完成全部译文的逐句母语审校。生产复核结果在发布后补充。
