# 邮件功能稳定性检查

## 结论

最近的故障包含真实的代码回归和入口权限遗漏，数据库每日读量超额还放大了故障表现。之前只修复报错入口，没有把共用页面的其他入口、异步加载失败和缓存恢复一起验收，因此不能把此前的单点修复等同于全部问题已经解决。

本次修复以下已确认的问题。生产登录态全流程和完整负载周期仍未完成验证，不能据此保证所有功能永远不会再出问题。

## 原因与修复

| 问题 | 触发条件与原因 | 本次处理与验证 |
| --- | --- | --- |
| 控制面板附件打不开 | 全部邮件详情仍使用普通用户附件接口，其他账号或已删除邮件被所有权检查拒绝 | 独立附件入口要求查看全部邮件权限；测试覆盖有权限、无权限、跨邮件附件及内嵌图片不能作为普通附件下载 |
| 详情正文或附件为空 | 列表先返回摘要，第二次后台请求正文；正文请求失败只记录错误，摘要仍可进入空详情 | 一次请求完整列表，写入详情后才显示；失败进入可重试状态；每页列表请求从两次降至一次 |
| 切换后出现旧列表 | 列表请求锁丢弃刷新操作，旧请求返回后可能覆盖新邮箱或筛选 | 新刷新替代旧请求，旧结果及旧请求结束回调失效；浏览器验证延迟旧请求不覆盖新列表 |
| 单封异常邮件导致整页无法显示 | 状态图标直接读取未定义的状态对象 | 未知状态使用通用图标和已翻译的未知标签；浏览器用未知状态邮件验证正文、图片及下载 |
| 临时邮箱本地正文完整但图片缺失 | 缓存命中正文后立即返回，即使内嵌图片保存失败也不再申请在线地址 | 在线时补取缺失图片，同时保留本地正文；验证首次图片失败、重新打开恢复、离线可读及邮箱切换隔离 |
| 隐藏页面持续请求 | 普通邮箱和全部邮件缺少页面可见性检查；管理页循环未停止，错误后未退避 | 隐藏、离开或销毁页面暂停刷新；失败退避至30秒、60秒，最多5分钟；带筛选的管理页不混入未匹配的新邮件 |
| 更换登录账号残留旧邮件 | 私有详情状态和缓存没有绑定登录账号，未完成请求可能在退出后写回 | 私有会话切换清理与请求失效；临时邮箱本地历史不受影响；测试覆盖换账号和退出期间的未完成请求 |
| 网络403导致页面反复刷新 | 请求错误处理直接刷新页面并返回空结果 | 错误正常拒绝，由页面显示恢复状态和退避；不再触发自动整页刷新 |
| 附件误下载错误正文 | 登录或权限业务错误可能使用HTTP 200返回JSON，浏览器只检查HTTP状态 | 附件读取拒绝JSON业务错误，不生成伪附件下载 |
| 已离开页面仍弹出预览 | 图片预览请求完成后没有检查当前邮件或预览状态 | 返回结果检查请求版本与当前邮件；离开或关闭后旧预览结果失效 |
